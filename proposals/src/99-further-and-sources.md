# Further open problems and sources

These are smaller or more specialised problems. Each could become a thesis chapter or a master's project.

| Problem | Question | Ref. |
|--------------|--------------------------------------------|----------------|
| Games born by day 4 | Tighten Suetsugu's bounds $10^{28.2} \le g(4) \le 4 \times 10^{184}$; structure and dimension of the lattices $L_3$ and $L_4$ | E7 |
| Hereditarily transitive games | How many are born on day n? Which other families form planar lattices? | E7 |
| Universal rulesets | Is Toppling Dominoes universal? Smallest boards realising all day-2 values | E19 |
| Multiplayer games | Misère three-player Nim (podium rule) with fewer players than heaps; other preference orders | E22 |
| Enumeration | A formula for the number of P-positions of Nim with $2n$ tokens | E15 |
| Lattice games | Efficient winning-move algorithms for squarefree lattice games (Miller–Guo) | E16 |
| Transfinite Chomp | Nim-value of $\omega \times 4$; Stratification Conjecture | D1 |
| 3-D Chomp | Gale's US\$300 infinite 3-D Chomp | D1 |
| Polychromatic Chomp | General formula for red–blue–green poset games | D1 |
| Sprouts | Extend perfect play past 11 dots (normal and misère) | C2 |
| Hexadecimal games | Arithmetic periodicity, $G(n+p) = G(n) + s$ with saltus $s$: is .f6 period 43, saltus 32 (our data break at $n = 1929$)? Analyse .9, .7f, .e, .b6, .b33b | A3 |
| Atomic weight | Is the exceptional set of atomic-weight calculations finite for every ruleset of bounded nim-dimension? | E18 |

- A. Flammenkamp, [octal game tables](http://wwwhomes.uni-bielefeld.de/achim/octal.html).
- [OEIS A395248](https://oeis.org/A395248): Sprague–Grundy values of .007.
- Recent misère work: [Invertibility modulo dead-ending universes](https://ar5iv.arxiv.org/html/1509.01576); [sums of P-free forms (arXiv 2506.05257)](https://arxiv.org/html/2506.05257v1); [Siegel, dead-ending universes (arXiv 2312.16259)](https://arxiv.org/abs/2312.16259v1).
- [Node-Kayles on Trees (arXiv 2512.24221)](https://arxiv.org/pdf/2512.24221).
- Software: [CGSuite](https://www.github.com/aaron-siegel/cgsuite) (installer in this repo: `cgsuite-2.1.1.sh`).
