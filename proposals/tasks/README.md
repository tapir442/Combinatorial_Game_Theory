# Task breakdown of the PhD proposals

Each proposal (see `../src/`) is split into small tasks of about 1–8 weeks.  Every task
has an ID, a rough effort, its dependencies, and a concrete output.  Tick tasks off
directly on GitHub.

| Proposal | File | Tasks | Fastest first result |
|---|---|---|---|
| 1 Octal periodicity | [p1-octal-periodicity.md](p1-octal-periodicity.md) | 19 | Ward's formula, case c = a + b, for small a |
| 2 Misère algebra | [p2-misere-algebra.md](p2-misere-algebra.md) | 16 | Classifying misère quotients beyond order 18 |
| 3 Loopy temperature | [p3-loopy-temperature.md](p3-loopy-temperature.md) | 14 | Formal proof of Sentestrat |
| 4 Complexity | [p4-complexity.md](p4-complexity.md) | 15 | Wolfe's sums of switches (E3) |
| 5 Scoring and loopy games | [p5-scoring-loopy.md](p5-scoring-loopy.md) | 14 | Solving Brushes |
| 6 Placement games | [p6-placement-games.md](p6-placement-games.md) | 15 | Domineering value and temperature database |

Conventions:

- **Effort** is in weeks of full-time work and is a rough guess.  Open-ended research
  tasks are marked *open*.
- **Needs** lists the tasks that must be done first.
- Problem codes (A2, E13, …) refer to Nowakowski, *Unsolved problems in combinatorial
  games*, Games of No Chance 6 (2025).
- `octal-explorer` is the tool in this repo (C + the Python package `octalgames`).

Every proposal also needs these standard PhD tasks: a literature report (month 3),
a qualifying or transfer report (month 12), one or two conference talks per year
(CGT Colloquium, Integers conference, Games of No Chance meetings), and the thesis
(last 6 months).
